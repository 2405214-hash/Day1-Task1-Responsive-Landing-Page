# FocusFlow - Responsive Landing Page

## About

FocusFlow is a responsive productivity platform landing page designed using HTML5 and CSS3.

## Features

- Semantic HTML structure
- Flexbox navigation bar
- CSS Grid feature cards
- Responsive hero section
- Hover effects
- Mobile, tablet and desktop layouts

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Project Structure

Day1-Task1-Responsive-Landing-Page/
├── index.html
├── style.css
└── README.md

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open index.html in your browser.
